Realtime Ambilight

This plugin analyses the picture on the server and sends temporary realtime colours to WLED while something is playing. When playback stops it hands control back to WLED. Your WLED power limit is never changed.

1. Which TV do these LEDs belong to?

Pick the device you actually watch on; only that device drives the LEDs. The list is ordered by last used, so your TV is usually near the top.
Recommended: pick your TV. If you leave this on All devices, the LEDs react to every device that plays something — including a phone in another room.

Turn this off to release the LEDs straight away without losing the rest of your settings. Default: on.

2. Which WLED controller?

The finder asks the local network which devices announce themselves as WLED, then confirms each one through WLED's public info page. Nothing on your WLED is modified.

The LED count after each name helps you recognise the right controller.
Only needed when the scan finds nothing, for example when your WLED is on a different network or VLAN. Enter the same address you use in your browser, such as 10.0.0.8. Default: discovered automatically.
WLED's web port, used to read its status and to release the LEDs cleanly. Only change this if your WLED runs on a non-standard port. Default: 80.
How the colours reach WLED. Automatic picks the right protocol for your LED count: Raw RGB up to 490 LEDs, DDP above that. Default: automatic — leave it alone unless you have a reason to force one.
